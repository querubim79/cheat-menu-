# Cheat Menu (Fabric 1.21.1) — client-side

Requisitos: JDK 21, Gradle 8.8+ (ou use o wrapper do template oficial), Fabric API.

Build:
    gradle wrapper --gradle-version 8.10
    ./gradlew build
O .jar sai em build/libs/cheatmenu-1.0.0.jar (não use o -sources.jar).

Uso: Right Shift abre o menu (muda em Controles > Cheat Menu).
